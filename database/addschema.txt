-- Make sure order_process table has a row for step 1 after checkout.

After creating a new order in cart_api.php (ACTION: checkout), after the order is successfully created, immediately create the order_process entry for Step 1 with status 'Completed'. This will make Step 1 appear as '🟢 COMPLETED' in the order process page right from checkout.

Run this query right after order creation (line 266-270 in cart_api.php):

INSERT INTO order_process (order_id, process_step_id, status, completed_by, completed_at, process_date)
SELECT o.order_id, sp.process_step_id, 'Completed', o.customer_id, NOW(), CURDATE()
FROM orders o
CROSS JOIN process_steps sp ON sp.step_number = 1
WHERE o.order_id = ?;

Replace ? with $orderId.

Also, after this insertion, update the order status to 'In Progress' so the order is visible in the active process:

UPDATE orders SET order_status = 'In Progress' WHERE order_id = ?;

Replace ? with $orderId.

This ensures:
- Step 1 badge shows '🟢 COMPLETED' immediately after checkout
- The order is visible in the active process
- When admin advances to Step 2, Step 1's status changes to 'In Progress' and shows '🔵 IN PROCESS'
- Admin approval of Step 2 then marks Step 1 as 'Completed' (already done by main admin approval flow)
